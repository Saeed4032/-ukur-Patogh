# پاتوق تخته‌نرد — راهنما و فهرست تغییرات

## ساختار پروژه

```
index.html            فقط HTML (دیگه CSS و JS داخلش نیست)
css/style.css         همه‌ی استایل‌ها
js/app.js             منطق اصلی برنامه (بازیکن‌ها، بازی‌ها، رتبه‌بندی، تورنمنت…)
js/local-mode.js      حالت آفلاین/محلی
js/supabase-loader.js لود کتابخانه‌ی Supabase از CDN اگه فایل محلی لود نشد
js/sync.js            همگام‌سازی با Supabase و ورود/خروج
js/signup.js          فرم ثبت‌نام
js/sounds.js          صداها
js/bottom-nav.js      منوی پایین
js/scroll.js          رفتار اسکرول
fonts/                فونت وزیرمتن (self-host) + مجوز OFL
service-worker.js     کش آفلاین (نسخه v5)
supabase/security.sql امن‌سازی دیتابیس (RLS + تریگرها)
```

## کارهایی که شما باید انجام بدید

1. **اجرای SQL امنیتی (مهم‌ترین مورد):** در پنل Supabase به بخش SQL Editor برید، محتوای `supabase/security.sql` رو کپی و اجرا کنید. قبلش از دیتابیس بکاپ بگیرید.
   - بعد از اجرا: بازی رو فقط صاحبش یا ادمین ویرایش می‌کنه، حذف واقعی بازی و بازیکن و تغییر تورنمنت فقط با ادمینه، `user_id` و نام ثبت‌کننده‌ی لاگ رو سرور تعیین می‌کنه و لاگ‌ها رو فقط ادمین می‌بینه.
   - بازی‌های قدیمی که `user_id` ندارن فقط توسط ادمین قابل ویرایش‌اند (دستور اختیاری انتهای فایل SQL برای اختصاص دادنشون به یک ادمین).
2. **رمز قوی برای حساب‌های ادمین** (Authentication → Users → Reset password).
3. **CAPTCHA:** Authentication → Attack Protection → Enable CAPTCHA protection. سرویس hCaptcha یا Cloudflare Turnstile رو انتخاب و Secret Key رو وارد کنید. بعد از فعال‌سازی، کلاینت هم باید توکن کپچا رو در `signUp`/`signInWithPassword` بفرسته (`options.captchaToken`)؛ اگه خواستید این بخش رو هم اضافه می‌کنم — فقط Site Key لازمه.
4. **Rate limit:** Authentication → Rate Limits؛ محدودیت ثبت‌نام و ورود رو پایین بیارید.
5. **تأیید شماره (OTP پیامکی):** الان ثبت‌نام با ایمیل ساختگی `شماره@backgammon.local` انجام می‌شه و مالکیت شماره بررسی نمی‌شه. برای OTP واقعی باید در Authentication → Providers → Phone یک سرویس پیامک (Twilio, MessageBird, Vonage, Textlocal) تنظیم بشه یا با Auth Hook «Send SMS» به یک سرویس ایرانی (مثل کاوه‌نگار) وصل بشه. بعد از تنظیم سرویس پیامک، تغییر فرم ثبت‌نام به `signInWithOtp({ phone })` + `verifyOtp` کار ساده‌ایه.
6. **حذف `game.html` و `replace.ps1` از هاست**، اگه قبلاً آپلودشون کرده بودید.

## تغییرات انجام‌شده

### امنیت
- فایل `supabase/security.sql`: فعال‌سازی RLS روی هر چهار جدول، تابع `is_admin()` بر اساس `app_metadata.role`، تریگر تعیین مالک بازی، تریگر پر کردن `user_name` لاگ از توکن، محدودیت حجم عکس.
- موقع **ویرایش** بازی دیگه `user_id` فرستاده نمی‌شه (فقط موقع ساخت بازی جدید). قبلاً ویرایش بازی یکی دیگه مالکیتش رو عوض می‌کرد.
- رکوردهای حذف‌شده (tombstone) هم بدون `user_id` فرستاده می‌شن.
- دکمه‌های «تغییر نام» و «حذف عکس» فقط برای ادمین نمایش داده می‌شن و خود عملیات هم دوباره چک می‌شه. (قبلاً شرط ادمین در `renderPlayers` تو در تو و تکراری بود و تغییر نام برای کاربر عادی نیمه‌کاره انجام می‌شد و با سینک بعدی برمی‌گشت.)
- `game.html` (نسخه‌ی قدیمی بدون چک ادمین) حذف شد.

### باگ‌ها
- **Service Worker:** فقط صفحه‌ی اصلی با کلید `index.html` کش می‌شه؛ HTML/JS/CSS اول از شبکه گرفته می‌شن (network-first) و در حالت آفلاین از کش، پس نسخه‌ی جدید با یک بار رفرش دیده می‌شه.
- `replace.ps1` (خراب و وابسته به مسیر `C:\work2`) حذف شد.
- هندلر تکراری دکمه‌ی ثبت‌نام حذف شد.

### مصرف اینترنت
- polling و realtime حالا **بدون عکس‌ها** بازیکن‌ها رو می‌گیرن. عکس‌ها فقط موقع ورود، سینک دستی، یا هر ۱۰ دقیقه یک بار دانلود می‌شن.

### رابط کاربری (نسخه‌ی ۲)
- صفحه‌ی ثبت: دکمه‌ی «حذف آخرین بازی» کوچک‌تر و کم‌رنگ‌تر شد تا با دکمه‌ی ثبت اشتباه گرفته نشه (همچنان تأیید می‌خواد). آمار زیر اسم بازیکن به شکل «۱۵ بازی · ۵۳٪ برد» نوشته می‌شه. برچسب‌ها برای لمس بزرگ‌تر شدن.
- تاریخچه: فیلترها پشت «فیلترها، مرتب‌سازی و خروجی» جمع شدن و فقط جستجو همیشه دیده می‌شه. ۲۰ بازی نمایش داده می‌شه و بقیه با دکمه‌ی «نمایش بیشتر». دکمه‌های ویرایش و حذف کوچک شدن. (باگ: بعد از برگشتن به این تب، دکمه‌های ویرایش و حذف گاهی کار نمی‌کردن؛ درست شد.)
- جدول: اسکرول‌بار تیره و باریک شد و ستون نام بازیکن موقع اسکرول افقی ثابت می‌مونه.
- آمار: رکوردهایی که برای همه‌ی بازیکن‌ها مقدار دارن، به‌جای متن با «|»، به‌شکل برچسب‌های جدا نمایش داده می‌شن.
- تورنمنت: دکمه‌ی «شروع تورنمنت جدید» کم‌رنگ‌تر شد.
- ورود: عنوان فیلد «شماره موبایل یا نام کاربری» شد و دکمه‌ی نمایش رمز (👁) اضافه شد.
- دسکتاپ: دکمه‌ی ⚙️ داخل هدر قرار گرفت.

### تم‌های لوکس
- سه تم جدید در «تنظیمات ← انتخاب قالب»: «💎 شاهانه» (مشکی و طلایی)، «♣️ زمرد سلطنتی» (سبز ماهوتی و طلایی) و «🪵 گردو و چرم».
- دکمه‌ها، تب‌ها و گزینه‌ها شیشه‌ای (مات و نیمه‌شفاف) هستن و درخشش طلایی داخلی دارن. موقع لمس درخشش بیشتر می‌شه و گزینه‌ی انتخاب‌شده طلایی شیشه‌ای و درخشان دیده می‌شه.
- در این تم‌ها عنوان برنامه درخشش طلایی متحرک داره، کارت‌ها لبه‌ی طلایی ظریف دارن و دکمه‌ی ثبت با گرادیان طلایی و برق عبوری نمایش داده می‌شه. برای کاربرهایی که «کاهش حرکت» رو در گوشی فعال کردن، انیمیشن‌ها خاموش می‌شن.

### کیفیت کد
- CSS و JS از `index.html` جدا شدن و فرمت شدن.
- تغییر `Storage.prototype.setItem` حذف شد؛ حالا تابع ذخیره‌ی برنامه (`put`) مستقیم سینک رو خبر می‌کنه.
- `escAct` از همون تابع `esc` اصلی استفاده می‌کنه.
- فونت وزیرمتن محلی شد و وابستگی به Google Fonts حذف شد.

## نکات بعد از به‌روزرسانی
- چون Service Worker عوض شده، اولین بار کاربرها ممکنه نسخه‌ی قبلی رو ببینن؛ با یک رفرش (یا بستن و باز کردن اپ) نسخه‌ی جدید فعال می‌شه.
- هر بار فایل‌ها رو تغییر دادید، مقدار `VERSION` در `service-worker.js` رو یک واحد بالا ببرید تا کش قدیمی پاک بشه.

## مواردی که هنوز پیشنهاد می‌شه (نیاز به تغییر ساختار دیتابیس)
- انتقال عکس‌ها به Supabase Storage به‌جای base64 در جدول و localStorage.
- شکستن `tournament_state` به جدول‌های جدا یا یک تابع RPC، تا تغییرات هم‌زمان همدیگه رو پاک نکنن.
- انتخاب تاریخ شمسی در فیلتر تاریخچه (الان تقویم میلادی مرورگره).
- انتقال لیست `BLOCKED_PLAYERS` و `NAME_MAP` از کد به دیتابیس.
